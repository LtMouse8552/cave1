# 许可证讲解技能

## 何时使用
用户想理解某个许可证的含义、区分不同许可证，或想弄清“我这样做合规吗”。

## 执行步骤
1. 如果用户给了具体的 SPDX 标识符，用 MCP 工具 `get_license_info` 查询要点。
2. 如果用户给的是一个 LICENSE 文件或目录，先 `read_file` 读取内容（目录则用 `scan_project_licenses`）。
3. 先用一句话给出结论（例如“可以商用，但必须保留版权声明”）。
4. 再分点解释：允许什么、禁止什么、必须做什么。
5. 如果问题涉及多种许可证的对比，用 MCP 工具 `check_compatibility` 辅助判断，然后用一张对照表呈现。

## 讲解规范
- 面向刚接触开源合规的大学生，避免法律术语堆砌，第一次出现的术语要解释。
- 只基于工具返回的信息和许可证原文讲解，不凭记忆补充条款细节。
- 涉及“是否违法”“是否会被起诉”这类问题时，明确说明：助手只能指出风险点，不能给法律结论。
- 结尾提醒：“正式合规判断请以许可证原文为准，必要时咨询法务。”
