# 代码讲解技能

## 何时使用
用户想理解本课程仓库中某个文件或某段代码的作用时。

## 执行步骤
1. 用 `ls` 或 `glob` 找到目标文件，用 `read_file` 读取全文。
2. 先用一句话说明这个文件“解决什么问题”。
3. 画出调用关系，例如：`app.py 调用 agent.build_agent，再调用 create_deep_agent`。
4. 按代码顺序分块讲解，每块包括：
   - 这块代码做什么（一句话）
   - 关键 API 或语法点（初学者可能不懂的地方）
   - 如果要修改，应该改哪里
5. 最后给出 2 到 3 个“动手练习”，让学生通过修改代码加深理解。

## 讲解规范
- 面向刚学 Python 的大学生，避免堆砌术语，第一次出现的术语要解释。
- 引用代码时注明文件名和行号范围。
- 只读不改：本技能不修改任何源文件。
