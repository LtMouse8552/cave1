# 声速测量虚拟仿真 · 进阶版（扩量程）

一个纯前端的物理实验虚拟仿真项目：模拟大学物理实验「声速测量」，在浏览器中即可完成谐振法 / 相位法 / 时差法测量超声波声速的全过程，并在原有基础上扩展了量程与进阶功能。

## ✨ 功能特点

- **单文件零依赖**：全部功能封装在一个 HTML 文件中，双击即可运行，无需安装任何环境
- **仿真示波器**：内置示波器面板，实时显示李萨如图形与波形
- **多种测量方法**：支持共振干涉法（振幅极值法）、相位比较法等经典测量方式
- **扩量程进阶版**：相比基础版扩展了测量量程，支持更多组数据采集
- **数据记录与处理**：自动记录测量数据，支持逐差法计算声速并给出误差分析
- **移动端适配**：响应式布局，手机 / 平板 / 电脑均可操作

## 🚀 使用方式

直接用浏览器打开 `声速测量2.0.1.html` 即可开始实验。

建议流程：

1. 了解实验原理与仪器面板
2. 调整信号频率，找到换能器谐振状态
3. 移动接收换能器，按所选方法逐点记录数据
4. 使用内置数据处理功能（逐差法）计算声速并查看误差

## 🛠 技术栈

- HTML5 + CSS3 + 原生 JavaScript（Canvas 绘图）
- 无任何外部依赖与构建步骤
